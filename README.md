# 🎓 Trainer Portfolio Dashboard UI

A modern, minimal, and user-friendly **Trainer Portfolio Dashboard UI** designed for online learning platforms.  
This interface focuses on trainer credibility, experience, reviews, and seamless navigation for students.

## 🚀 Features

✨ Clean & modern dashboard layout  
🧑‍🏫 Trainer profile with experience & achievements  
📊 Ratings, reviews & student statistics  
💼 Work experience timeline  
🔍 Search bar for courses & trainers  
📱 Responsive-friendly UI structure  
🎯 Clear CTAs (Request Session, Portfolio)

---

## 🧩 Sections Breakdown

### 📌 Sidebar Navigation
- 🏠 Home  
- 📅 Schedule  
- 🎓 Trainers  
- 📚 Policy Library  
- ⚙️ Preferences  
- 🚪 Logout  

### 👤 Trainer Info Card
- Profile image & contact details  
- Social links (LinkedIn, GitHub, Instagram)  
- Experience highlights  
- Short professional bio  
- CTA buttons:
  - 🎤 Request Session
  - 📂 Portfolio

### 💼 Work Experience
- Role-based experience cards  
- Company name & duration  
- Clear hierarchy for seniority

### ⭐ Ratings & Reviews
- Overall rating score
- Student feedback cards
- Growth statistics graph
- Total ratings count
